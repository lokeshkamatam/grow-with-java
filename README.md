# Grow With Java — Jobs & Tech Updates Website

An original, responsive landing page inspired by the visual quality of modern job-update websites.
It is NOT a copy of Job Updates Bro.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
- Replace sample job data in `js/script.js`
- Update Instagram/YouTube links in `index.html`
- Replace the GWJ text logo with your own logo if desired
- Connect job cards to your backend/API later
